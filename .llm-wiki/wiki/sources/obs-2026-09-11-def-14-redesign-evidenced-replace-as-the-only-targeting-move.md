# 🔴 Observation: Def 14 redesign: evidenced replace as the only targeting move

User critique: current Def 14 targeting (remove/add by band geometry alone) is semantically vacuous — wdmh derives to any target whatsoever; selection is the only semantic guard and is one node deep. Amendment decided in direction (not yet written into doc): (1) Def 14 licenses replace for ALL misfits S2+S3, as the only targeting move; remove/add demote to replace's interior mechanics (§7 interleaving). (2) Replace is licensed by EVIDENCE — a held correspondence kline n:ν′ with n the node replaced, or a chain composed across hops; §10 progressive-path STM connotation witnesses become the evidence Def 14 reads. Selectability (t ∈ ν_A) unifies with the replace licence — selection chooses next hops, not final targets; done is a check. (3) Replace is asymmetrical per evidence shape: Denotation=contract (shed its gap, e.g. dh:[h2] sheds d), Canon=expand (witnessed granularity), Connotation=traverse (role hop, w:[o]); direction fixed by which side the derivation arrived from. Worked example: verb dh⇉[h] via denotation; object w⇉[o]⇉all⇉[a,l,l] via connotation chain + canon; subject m identity. Open consequences flagged: T1 demoted (traverse breaks D-monotonicity; termination = no-revisit strategy bound); γ must go slot-wise or path-integral (whole-content J punishes traversal); vacuity localised not eliminated (chains built from ungrounded S3 claims; countersign/ratification is the per-link quality gate). Engine precedent: pivot alignment (obs 2026-08-20) already implements this operationally (shared=S2, edge-hop=S3 node replaced by pivot counterpart, did+have→DH→had, what gap filled by [a,little,lamb]).
