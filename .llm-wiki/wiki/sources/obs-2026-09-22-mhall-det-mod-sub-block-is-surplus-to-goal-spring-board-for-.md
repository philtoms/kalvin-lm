# ⭐ Observation: mhall Det/Mod sub-block is surplus-to-goal spring-board for future scripts

Correction/settlement on the mhall.ks Det/Mod sub-block: the second canonicalisation (ALL => A=Det, L=Mod, L=O) is NOT required to meet the SVO goal — it is surplus-to-goal scaffold. Its purpose is a spring-board for future scripts testing deeper or more transitional relationships (wdmh.ks consumes it: ALL = O(bject), h(ad) => did have). MHALL is an ancient, multi-purpose script — part compiler challenge (duplicate-L binding, chained `Object < Query < ALL` syntax), part rationalisation challenge (2-hop Query underfit on the object slot). Authoring principle revealed: scripts may carry surplus scaffolding beyond the goal's requirements, whose value is realised by later scripts in the curriculum — goal-required structure and spring-board structure are different budget lines.
