# ⭐ Observation: All Kalvin wiki stub pages filled in

Filled in all 64 stub pages (44 concepts + 20 entities) in the Kalvin wiki. Every page now has a real Definition/Overview section drawn from CONTEXT.md (the truth document per AGENTS.md) and the two docs sources, with proper cross-links using the path-prefixed wikilink format (e.g. `[[concepts/canon]]`, not `[[canon]]`). Key lesson: this wiki requires path-prefixed wikilinks — bare `[[name]]` produces unresolved-link warnings. Pages follow a consistent shape: frontmatter → # Title → one-line description → ## Definition/Overview (with tables/quotes where useful) → ## Links (source links + concept cross-links). Concepts tied to live diagnostic questions (canonical-synthesis, silent-synthesis) are marked as diagnostic, not domain terms. After fill-in, recall quality visibly improved: queries now return real definition text in previews rather than `[Clear explanation]` placeholders.
