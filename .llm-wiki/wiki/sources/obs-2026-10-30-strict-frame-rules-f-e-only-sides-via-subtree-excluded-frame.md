# ⭐ Observation: Strict frame rules: F==E only; sides via subtree-excluded frames or child resolution

Strict frame rules implemented per user spec: frames enter the set ONLY via (a) F==E (candidate side covers entry side — immediate, at pairing) and (b) the S3 exchange (a U-side and O-side reentry stalled at S4 on the same signature). Resolution no longer frames F, and reentry resolution no longer frames its signature. Side satisfaction = region empty ∨ covered by a frame from OUTSIDE the subtree (frames carry their producing reentry; _chain(re) excludes the reentry and all ancestors — a subtree never satisfies itself with its own frames, fixing pop-skip leaks) ∨ its child reentry resolved (backwards propagation via resolved_by → _after(parent)). Candidate order: least content first (mu(side(c)) ascending — scaffolding before canons), which stops the goal-canon universal-donor peel (MHALL pairing every sub-region) that flooded the run. Trace (_trace) now selects ONE satisfier per side — the child's resolving row, the exchange pair, or the first source of the smallest covering frame — giving minimal paths: mhall 14/114 rows, wdmh 27/42; wdmh ends stalled-DH → … → resolved-DH (exchange last, matching the expected table's row order). Frame columns are now honest: wdmh rows 1-2 (F=Mary≠WDMH, F=what≠WDH) show NO frame.
