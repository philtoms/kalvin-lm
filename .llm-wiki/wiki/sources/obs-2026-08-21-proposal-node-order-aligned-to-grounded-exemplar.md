# ⭐ Observation: Proposal node order aligned to grounded exemplar

Added _align_to_grounded in expand_fit: before grading, both propose arms check whether signature_of(proposed_nodes) is grounded in LTM; if so the proposal adopts the grounded kline's node order (identities skipped). The proposed multiset is the misfit's answer but its order is a slot-accounting artifact — the grounded exemplar is the phrasing K knows. Effect: WDMH proposal became [Mary,had,a,little,lamb] (natural order) instead of [had,Mary,a,little,lamb], at the same S3 101 grade. Bypasses linguistic post-processing an observer would otherwise expect.
