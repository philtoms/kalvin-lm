# ⭐ Observation: TRS spec amended: mirror pairing D7, materialisation A-1

Amended docs/trs-significance.md per user rulings. (1) OQ-1 resolved: D7 switched to the mirror pairing — branch candidate is now ⟨U, N_O⟩ (underfit residual heads, overfit adjacency carries; each residual staged at its destination). Pure-direction fallbacks unchanged: ⟨O, N⟩ (pure overfit), ⟨σ, N_U⟩ (pure underfit) — these are the S3-sound forms. D5 amended: fit branch materialises ⟨F, N_F⟩ (store, like R1) rather than only selecting an already-held kline. D8 added. No-fabrication (P-4) restated: no new atoms, only re-compositions of held content. OQs renumbered: OQ-1 R3 splice, OQ-2 decode construction rule (containment-selection vs atom decomposition), OQ-3 grading, OQ-4 novel atoms. Can_D removed as vestigial.
