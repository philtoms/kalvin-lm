# ⭐ Observation: TRS spec: unpaired residual adjacencies, canonical re-entry loop

Fifth round on docs/trs-significance.md: R2/R3 restructured per user ruling. D6 REVERSED: R3 no longer preserves the candidate's signature — its product is canonical ⟨can(N′), N′⟩, which re-enters the TRS as a NEW ENTRY (prior signature discarded; S3 means no correspondence and none is asserted). D7 SUPERSEDED: the mirror pairing ⟨U, N_O⟩ is gone entirely — R2's misfit products are now the residual ADJACENCIES N_O and N_U themselves, unpaired ('there is no correspondence with U'): O ∧ U = ⊥ by construction, so pairing either residual as head would assert a nonexistent correspondence; each adjacency expands under R3 (choice of which = strategy). The pure-direction case table (⟨O,N⟩ / ⟨σ,N_U⟩) deleted with it. New D11: R3 is single pass; outcomes are (a) no substitutions → R4, (b) canonical re-entry with fresh band calculation; re-entry continues until a band routes to S1 or S4. R4 retitled 'terminal' with two arrivals: empty adjacency, or R3's no-substitution outcome. P-1 retitled 'Separated misfit'; P-3 states the loop's routing is total but arrival is not rule-guaranteed (strategy bounds re-entry depth). Diagram updated: N_O,N_U → substitute → N′ → ⟨can(N′),N′⟩ → new entry → repeat. Unified loop: S2→R2 project→R3 single-pass expand→canonical re-entry→new band; S1 stores, S4 ends; the re-entered object is an entry (transient, never valued, becomes knowledge only if one of its candidates reaches S1).
