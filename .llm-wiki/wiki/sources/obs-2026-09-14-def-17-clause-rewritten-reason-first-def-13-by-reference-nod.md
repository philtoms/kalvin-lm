# 🔍 Observation: Def 17 clause rewritten: reason-first, Def 13 by reference, node-opacity principle named

Phil critiqued the Def 17 absorption clause: it re-taught §6's canon expand/contract machinery (well-foundedness, "no new rule" disclaimer) while omitting the machinery by name, and buried the clause's reason. Rewrote per his direction — reason first, machinery by reference: "Absorption delivers the excess at the goal's own resolution. A compound node is opaque to licensing — occurrence reads nodes, never the atoms within them — so content absorbed as a lump is inert to everything held at finer resolution. Absorption therefore expands the terminal's nodes covering the excess to the resolution the goal's witness holds that content at, and no further, by Definition 13's Canon expand under its well-foundedness condition. Each expansion is an edge crossed." Notable: node-opacity of occurrence is the one genuinely NEW principle (implicit in Def 13/16's node-wise occurrence, never stated as such); the coarse-goal no-op case was cut as implied by "and no further"; "No new rule is involved" disclaimer replaced by the Def 13 reference itself; terminology switched refinement→expansion to match the doc's own vocabulary (aligned CONTEXT.md Slot entry, worked-example Step 3 "absorption expansion", probe note/docstring). Probe re-run 7/7 PASS. Not committed.
