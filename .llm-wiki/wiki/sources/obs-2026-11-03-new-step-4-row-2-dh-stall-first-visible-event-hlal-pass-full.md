# 🔍 Observation: New step-4 row 2 (DH stall) = first visible event; HLAL pass fully elided

After the parent-origin bar, wdmh step-4's table row 2 is the DH stall at depth 3 — not because DH is the next reentry after the opening, but because it is the first VISIBLE event. HLAL (stack top after row 1) runs its whole 8-pairing pass with zero visible rows: the three MHALL-sig candidates were the only F==E mints (the only signatures containing HLAL) and are now barred, and no close is possible with no frames minted — so every event is an elided plain pair. That invisible pass pushes 9 depth-3 children, LAST is DH (the O-side of HLAL × had:[did,have] — the offering is can({did,have}) beyond HLAL). LIFO makes DH the next reentry; its candidate list is empty (did:[did]/have:[have] are identities; origin had:[did,have] has sig `had`, no overlap, barred as parent candidate anyway) → S4 stall, always rendered → row 2. The stall waits: WDH × what:Object later pushes a second DH from a different parent → exchange mints joint frame DH (depth 6) → both resolve → WDH resolves → opening grounds. HLAL's visible rows move to the step's tail (re-surface closes via ALL canon + framed had).
