# 🔴 Observation: Def 17 slot derivation formalised; walk licence is occurrence, ending is arrival

Formalised slot sub-hops as Def 17 (slot derivation) in docs/ks2.md §10: a misfit decomposes per node — each node of ν_A carrying a gap atom is a slot seeking the goal's excess e. A slot with a licensed replace fires it; a slot with none (the misfit asks at that node) may be walked: queue n:[n], derive ⊢_M with NO goal, licence = occurrence (either side of a held correspondence occurring in the walk's nodes — Def 16's clause is the forward half), scoping clause explicitly inapplicable (role nodes orthogonal to both contents — this was the formalisation gap: traverses like w⇉[o] INCREASE the misfit mass, so the walk cannot be content-scoped). Endings: arrival (σ(ν) ∧ e ≠ ∅, then granularity free via canon-mode) or stuck (ask localised to one slot); goal-less derivation has no done. Absorbed end state = the composed correspondence (signature n, witness the arrival, Ĥ = edges crossed); main line consumes it — targeting-licensed because arrival content is excess, mass strictly decreases. Trigger is exactly the misfit-ask: walking is how a missing licence is BUILT. §8 stuck now requires no replace AND no arriving walk; reentry params (M_k, B_k) allow B_k = none; progressive path paragraph now points at Def 17. CONTEXT.md gains a Slot glossary entry (avoid: subgoal, subroutine, task). Worked example re-verified against Def 17 end-to-end (trigger, forward/reverse occurrence, arrival, expand-as-granularity-freedom, absorb, consume).
