# ⭐ Observation: KScript semantic model settled via grill

Grilled session established the semantics of .ks scripts. A script is a structured document; valid without annotations. K is purely structural — letter meanings are never encoded into klines. Annotations exist for the session's agent (instruct in high-level language what the structure means) and for the compiler (Word Binding); never for the trainee. `==` COUNTERSIGNS is connotes+denotes shorthand: two traversable structures (MHALL:[SVO] and SVO:[MHALL]) K uses to traverse between concepts. MTS need not spell its annotation — a mismatch compiles fine and is only a missed opportunity for the agent. The harness decodes output into words; the agent judges decoded trace/grounded/work_list and must call semantic gibberish gibberish rather than charitably reading near-misses as on-track.
