# ⭐ Observation: Positional gap fills in pivot graft unblock multi-gap proposals

Pivot graft now handles multiple gaps via positional fills: gap slots carry None placeholders through resolution (preserving canon order), and gaps (canon-ordered) pair with pivot leftovers (pivot-ordered) by relative position. The old rule refused two or more open gaps as 'guessing which leftover answers which gap' — but positional alignment is alignment, not guessing. New guard: gap count must equal leftover count. DFPAS (did Fred pet a sheep, added to mhall.ks) now proposes against DMHAS/DMHAL/MHALL pivots, all graded S3 127 — confident long-worded negatives (fully understood ask, guessed slots denied connotation by the script), a nice validation of boundary-relative ProposalAggregator grading.
