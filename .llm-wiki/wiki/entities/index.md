# entities

## Concepts

- [Auto-Tune](auto-tune.md) — Experimental loop where an LLM coding agent tunes Kalvin's rationalisation code by running sessions and editing the significance model.
- [Harness](harness.md) — The multi-agent runtime that loads agents as participants and routes role-addressed messages between them.
- [Kalvin](kalvin.md) — The rationalising system whose entire world is built from klines.
- [KScript](kscript.md) — The language that authors training material by declaring klines and labelling them with Target Significance.
- [LTM (Long-Term Memory)](ltm-long-term-memory.md) — Persistent knowledge surviving across sessions; a kline in LTM is grounded.
- [STM (Short-Term Memory)](stm-short-term-memory.md) — The lowest tier in the write cascade and Kalvin's event register; empty at session start.
