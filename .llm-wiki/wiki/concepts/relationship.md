# Relationship

A kline **structure**: the single-node misfit.

## Definition

A non-terminal whose signature associates with exactly one other value
(`{A: [B]}`, `A != B`). This is the connote/denote shape, named in its own right
because the engine treats it as a distinct routing class — a candidate for
reciprocal grounding / [[concepts/ratify|countersignature]] — separate from
multi-node misfits (no-fit/underfit/overfit), which propose rather than
associate.

A relationship is a kind of [[concepts/misfit]]; it is _not_ a synonym for "any
non-identity" (a [[concepts/canon]] is also a non-identity, and a multi-node
misfit is too).

_Avoid_: link (too vague), association (overloaded with the connote action),
any-non-identity.
