# Scaffolding

KScript entries that provide grounding context for other entries.

## Definition

Scaffolding is structurally identical regardless of origin; the difference is
only _when_ the entries are created:

- **pre-compiled** — written into the original script by the curriculum designer
- **reactive** — written by the [[concepts/supervisor]] when Kalvin's S2/S3
  [[concepts/proposal|proposals]] mismatch expectations

Each scaffold adds grounded structure close enough to existing knowledge,
gradually raising a query's [[concepts/significance]]. Teaching proceeds by
confirming, correcting, or instructing (the last is scaffolding) in response to
the trainee's partial understanding.
