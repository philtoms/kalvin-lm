# Engine first

A process discipline from the behaviour notes.

## Definition

> The engine is the target; the curriculum is the lever. Suspect the engine
> before retreating to .ks authoring.

When a training run misbehaves, the engine is the more likely culprit than the
[[entities/kscript|KScript]] source. Read the trace, find where
[[concepts/cogitation]] or [[concepts/grounding]] diverged from expectation, and
edit the engine/significance code first. Only then, if the engine is correct and
the source is genuinely wrong, edit the curriculum.

This is the operating posture for [[entities/auto-tune|auto-tune]] sessions.
