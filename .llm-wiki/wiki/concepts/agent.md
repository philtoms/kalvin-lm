# Agent

A participant that forms its own **significance** on a kline — a subjective
grading.

## Definition

Every agent assesses a kline independently and attaches its own
[[concepts/rational-significance]]. Three roles, each registered on the
[[concepts/harness]] bus, determine rationalising strategies:

- [[concepts/trainee]] — Cogitation
- [[concepts/trainer]] — Cogitation + [[concepts/escalation|Escalation]]
- [[concepts/supervisor]] — Oracle, Human-in-the-loop, etc.

The role determines what the agent does with the klines it receives; the
significance each attaches is its own private derivation.
